# HubTask

A modern task management and collaboration platform.

## Local Development

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```

## Features

- Task Management (Tasks & Projects)
- Team Collaboration
- Chat
- Analytics
- Leave Requests
- Content Management
